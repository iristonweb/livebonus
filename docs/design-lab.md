## B) CONCEPT EXPLORATION

### CONCEPT A: "Nocturne Blueprint" ⭐ SELECTED

**Фон:**
- Deep navy/black base (#0a0e14)
- Blueprint grid overlay (subtle, technical)
- Aurora glow layers (cyan/teal gradients, animated)
- Noise texture (controlled opacity, 0.02–0.04)
- Scanlines (subtle, horizontal, animated)

**Типо:**
- Headlines: Monumental sans (Manrope/Inter bold, 38–56px, tight tracking)
- Body: System sans (Inter, 16px, readable line-height)
- Accents: Monospace for technical data (13px)
- Hierarchy: Clear, editorial rhythm

**Навигация:**
- Floating dock/capsule (desktop)
- Bottom dock (mobile)
- Active states: energy edge glow
- Premium "Войти" button

**Карточки:**
- Dark glassmorphic base
- Blueprint border (subtle)
- Aurora glow on hover
- Scanline sweep on interaction (Signature 1)
- Energy edges (Signature 2)

**Формы:**
- Dark inputs with blueprint borders
- Focus: aurora glow ring
- Error: subtle red energy edge
- Loading: scanline animation

**Signature 1 (Interaction): Scanline Sweep**
- Horizontal scanline sweeps across interactive elements on hover/click
- Controlled timing (180–260ms)
- Subtle, premium, not distracting

**Signature 2 (Environment): Blueprint + Aurora + Noise**
- Blueprint grid background (CSS, subtle)
- Aurora glow layers (animated gradients)
- Noise texture overlay (CSS, controlled opacity)
- All controlled by CSS tokens

**Почему A:**
- Технический, но не перегруженный
- Premium feel без излишеств
- Чёткая визуальная система
- Хорошая читаемость
- Уникальный, но функциональный

## C) DESIGN PRINCIPLES

1. **Motion Budget:** 180–260ms transitions, controlled easing, max 2 animations per screen
2. **Visual Hierarchy:** Clear typography rhythm, consistent spacing scale (8/12/16/24/32/48)
3. **Premium Feel:** Subtle effects, not overwhelming, quality over quantity
4. **A11y First:** Focus-visible, contrast, keyboard nav, states
5. **Signature Consistency:** 2 signature приёма, доведены до идеала
6. **Performance:** No jank, optimized repaints, respects prefers-reduced-motion
