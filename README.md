# All in Guide — демо-сайт (All-in Guide)

Этот репозиторий — **локально запускаемый прототип** публичного лендинга + страницы с продукт-брифом/техспекой в формате Markdown.

## Требования

- **Node.js >= 20.9.0** (минимум для Next.js 16)
- npm / pnpm / yarn — любой менеджер пакетов

Проверка:
```bash
node -v
```

## Запуск

```bash
npm install
npm run dev
```

Откройте: http://localhost:3000

## Страницы

- `/` — публичный лендинг
- `/start` — «Начать оплату» (UX-черновик потока)
- `/partners` — «Подключить УК» (B2B-лендинг)
- `/apply` — анкета сразу после входа (как у Bilt)
- `/register` — расширенная регистрация + анкеты (физлицо/юрлицо; сдать/арендовать)
- `/docs` — полный Markdown-документ (бренд/продукт/UX/тех/юридическое)

## Где лежит контент

- `docs/all-in-guide.md` — основной документ (можно импортировать в Notion/Confluence)


## Регистрация (как у Bilt)

В шапке справа добавлена кнопка **«Войти / Регистрация»** — открывает модальное окно:
- Email → Телефон → SMS‑код (демо)
- Выбор сценария: Физлицо/Юрлицо и Сдать/Арендовать
- Затем перенаправление на `/register` с предзаполнением


- Подсказки город/район/метро: локальные списки + запросы к OpenStreetMap Nominatim (демо).
