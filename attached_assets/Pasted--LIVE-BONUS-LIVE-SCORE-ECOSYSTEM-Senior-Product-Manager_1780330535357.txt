# ГЛАВНАЯ ЦЕННОСТЬ

* арендаторов

# ОСНОВНЫЕ ПРОДУКТЫ

## 1. LIVE SCORE

Главный актив платформы.

Рейтинг арендатора.

Скоринг формируется на основе:

* истории платежей
* своевременности оплаты
* срока проживания
* количества объектов аренды
* подтвержденного дохода
* отзывов арендодателей
* истории споров
* уровня верификации

Результат:

оценка от 0 до 1000.

Пример:

910 = Premium Tenant

====================================================

## 2. LIVE PASSPORT

Цифровой паспорт арендатора.

Включает:

* рейтинг
* историю аренды
* историю платежей
* подтверждение личности
* рекомендации
* достижения
* статус

Пользователь может отправлять паспорт новому арендодателю.

====================================================

## 3. LANDLORD SCORE

Рейтинг арендодателей.

Метрики:

* возврат депозитов
* качество коммуникации
* количество жалоб
* прозрачность условий
* рейтинг арендаторов

====================================================

## 4. RENT GUARANTEE

Замена классического депозита.

Платформа предоставляет гарантию арендодателю.

Пользователь платит небольшую комиссию вместо заморозки крупного депозита.

====================================================
